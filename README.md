# SHTC3

SHTC3 es un sensor digital de humedad y temperatura optimizado para aplicaciones impulsadas por baterías y electrónica de consumo de gran volumen. 

El sensor ha sido diseñado para superar los límites convencionales en tamaño y consumo de energía para cumplir con los requisitos actuales y futuros, y ofrece una relación rendimiento-precio inigualable.

El empaquetado DFN de 2 x 2 x 0,75 mm. Permite aplicaciones incluso en el espacio más limitado.El sensor cubre un rango de medición de humedad de 0 a 100% RH y un rango de medición de temperatura de -40°C a 125°C con una precisión típica de ±2% RH y ±0,2°C. La amplia tensión de alimentación de 1,62 V a 3,6 V y un presupuesto de energía inferior a 1 μJ por medición hacen que el SHTC3 sea perfectamente adecuado para aplicaciones móviles o inalámbricas alimentadas por batería.
